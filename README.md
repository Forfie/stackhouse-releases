# Stackhouse — downloads

One-click HDR for real estate photographers using **Adobe Lightroom Classic** on macOS. Stackhouse finds your bracket sets, lets you check them, then stacks them, merges each to HDR with the right ghost removal for the scene, and applies your starting preset.

**[Download the latest version →](https://github.com/Forfie/stackhouse-releases/releases/latest)**

1. Open the `.dmg` and drag **Stackhouse** into **Applications**.
2. Open it. The welcome guide walks you through setup: Stackhouse installs its Lightroom plugin and starting presets, and asks you to let it use Lightroom's menus (System Settings › Privacy & Security › Accessibility).
3. Quit and reopen Lightroom Classic once, so it loads the plugin and presets.
4. In Lightroom, choose a shoot (a folder, Previous Import, or a selection), then click **Find Bracket Sets** in Stackhouse.

Stackhouse is signed and notarized by Apple, so it opens without security warnings, and it keeps itself up to date. Requires macOS 13 or later and Lightroom Classic 13 or later.

This repository only hosts release downloads.
